# Hoja de vida en GitHub Pages
1. Edita cada `index.html` y reemplaza los textos de ejemplo por tus datos.
2. Sube tu foto a `assets/img/foto.jpg`.
3. Google Drive: reemplaza `TU_ID_DE_ARCHIVO` en `index.html` y `documentos/index.html` por el ID de tu archivo.
4. Canva: pega el código embed en `capacitaciones/index.html`.
5. En GitHub: Settings > Pages > Deploy from a branch > main / (root).
